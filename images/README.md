# Фотографии OUR STORY

Добавьте сюда свои JPEG-фотографии с именами `photo1.jpg` … `photo10.jpg`. Соответствующие относительные пути и подписи находятся в массиве `GALLERY_ITEMS` в `../script.js`. До добавления снимков галерея показывает нейтральные декоративные заглушки; фотографии людей не загружаются из внешних источников.
