# OUR STORY

Личная интерактивная книга из десяти глав: откройте конверт, листайте страницы кнопками или свайпом и дойдите до анимированного финала. Это статический сайт — его можно открыть локально или разместить на GitHub Pages.

## Запуск и публикация

Откройте `index.html` в современном браузере или опубликуйте репозиторий через **Settings → Pages → Deploy from a branch**, выбрав корень (`/(root)`). Все пути сайта относительные, поэтому он поддерживает GitHub Pages с подпутём. Telegram Mini App также сохранён: страница вызывает `ready()` и `expand()`, но не читает и не отправляет личные данные.

## Музыка

Создайте папку `audio/` в корне сайта и поместите в неё два MP3-файла:

- `audio/oslepitelnaya.mp3` — «Ослепительная», KSB Music;
- `audio/rayskie-cvety.mp3` — «Райские цветы», Пошлая Молли.

После открытия конверта сайт запускает первую композицию; по её завершении играет вторая, затем цикл повторяется. Кнопка в шапке включает и выключает музыку.

## Структура

- `index.html` — конверт, книга, элементы управления, финальный экран и аудиоплеер.
- `script.js` — десять глав, перелистывание, свайпы, музыка и финальное сердце.
- `style.css` и `chapter-styles.css` — оформление, адаптивность и анимации.
- `envelope.js` — дополнительная совместимость для открытия конверта.
- `audio/` — музыкальные композиции, добавляются самостоятельно.
