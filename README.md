# OUR STORY

Личная интерактивная книга из семи глав: откройте конверт, листайте страницы кнопками или свайпом и дойдите до анимированного финала. Это статический сайт — его можно открыть локально или разместить на GitHub Pages.

## Запуск и публикация

Откройте `index.html` в современном браузере или опубликуйте репозиторий через **Settings → Pages → Deploy from a branch**, выбрав корень (`/(root)`). Все пути относительные, поэтому сайт поддерживает GitHub Pages с подпутём. Telegram Mini App также сохранён: страница вызывает `ready()` и `expand()`, но не читает и не отправляет личные данные.

## Добавление фотографий

Фотографии пока намеренно не загружены: главы 6 и 7 содержат пустые рамки 16:9. Чтобы заменить их снимками, сохраните изображения в папку `images/` и замените нужную рамку в `chapterMarkup()` файла `script.js` на `<img src="images/имя-файла.jpg" alt="Описание снимка">` с классом `chapter-photo`; в `style.css` задайте ей `width:100%; aspect-ratio:16/9; object-fit:cover; border-radius:10px`. Имена для рамок по умолчанию: `images/then-and-now.jpg` и `images/our-story.jpg`.

## Добавление музыки

Создайте папку `audio/` в корне сайта и поместите в неё два MP3-файла:

- `audio/oslepitelnaya.mp3` — «Ослепительная», KSB Music;
- `audio/rayskie-cvety.mp3` — «Райские цветы», Пошлая Молли.

После открытия конверта сайт запускает первую композицию; по её завершении играет вторая, затем цикл повторяется. Кнопка в шапке включает и выключает музыку. Браузеры могут не разрешать воспроизведение отсутствующего файла, пока соответствующий MP3 не добавлен.

## Файлы

- `index.html` — конверт, книга, элементы управления, финальный экран и аудиоплеер.
- `style.css` — оформление книги, адаптивная верстка и анимации.
- `script.js` — главы, перелистывание, свайпы, музыка и финальное сердце.
- `images/` — ваши фотографии (добавляются самостоятельно).
- `audio/` — две ваши композиции (добавляются самостоятельно).
